# \# PolySketch

# 

# Precision CAD 2D drafting, surface knife cutting, and exact polyline offsetting for Blender.

# 

# \## 📍 Where to find the tools

# Open the \*\*3D Viewport\*\*, press \*\*`N`\*\* to open the Sidebar, and navigate to the \*\*`Create`\*\* tab under \*\*`2D PolySketch`\*\*.

# 

# \---

# 

# \## 🛠️ Included Tools

# 

# \### Object Mode

# \* \*\*Poly Sketch\*\*: Interactive CAD drafting tool for creating custom 2D planar shapes and wire profiles on surfaces or custom workplanes with real-time snapping.

# 

# \### Edit Mode

# \* \*\*Poly Cut\*\*: Surface knife splitter that slices coplanar mesh faces along custom 2D polylines.

# \* \*\*Poly Offset\*\*: CAD-grade edge and face boundary offset with exact infinite-line miter math, unit input, live viewport preview, and automatic selection hand-off.
